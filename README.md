# MMC Mod Manager

**MMC (MongaManiaCorporation)**: менеджер модов для Cyberpunk 2077 с интерфейсом на русском и английском.
MMC (MongaManiaCorporation) mod manager for Cyberpunk 2077 with a Russian / English interface.

> Неофициальный фан-проект, не одобрен CD PROJEKT RED и Nexus Mods. Бесплатный, без платных функций.
> Что нужно по правилам Nexus, CDPR и лицензиям и зачем: [docs/COMPLIANCE.md](docs/COMPLIANCE.md).

## Возможности

- Автопоиск игры в Steam, GOG и Epic Games (или выбор папки вручную).
- Установка модов перетаскиванием: `.zip`, `.7z`, `.rar`, `.archive`, `.xl`, `.reds`, `.yaml`, папки.
- Сам раскладывает файлы по нужным местам: `archive/pc/mod`, CET-моды, redscript, TweakXL, RED4ext, REDmod.
- Включение/выключение модов одним переключателем, без потери файлов.
- Резервная копия оригинальных файлов игры, которые мод заменяет, и их восстановление при выключении.
- Поиск конфликтов и проверка зависимостей (CET, redscript, ArchiveXL, TweakXL, RED4ext).
- Профили: сохраняйте наборы модов и переключайтесь между ними.

### Установщики FOMOD

Если в архиве есть `fomod/ModuleConfig.xml`, открывается пошаговый мастер с картинками и описаниями
вариантов. Работают зависимые шаги и флаги, условные файлы и приоритеты. Выбор запоминается: при
обновлении мода он предлагается снова, а в коллекции передаётся другу.

### Зависимости

После установки мода с Nexus менеджер берёт список требований мода и предлагает поставить недостающие.
Фреймворки ставятся кнопкой «Установить» на вкладке «Фреймворки» и в карточке мода.

### Доктор

Читает логи redscript, RED4ext, CET, ArchiveXL, TweakXL и плагинов, склеивает повторяющиеся ошибки
и находит, какой мод их вызывает (по путям и именам файлов). Ещё показывает недостающие зависимости,
конфликты и недавние вылеты игры. Прямо оттуда мод можно выключить или открыть лог.

### Поиск виновника (вкладка «Доктор»)

Менеджер выключает половину модов (фреймворки остаются включены), игрок запускает игру и отвечает
«проблема есть» или «всё нормально». За ~log₂(N) запусков находится мод, из-за которого проблема.
В конце все моды возвращаются как были.

### История

Каждое изменение набора включённых модов записывается: что включили и что выключили. Кнопка «Вернуть»
возвращает набор к выбранному моменту (вкладка «Профили»).

### Игра запущена

Менеджер видит запущенный Cyberpunk2077.exe, предупреждает, что файлы заняты, а когда игра закрывается,
сам запускает «Доктора» и сообщает о найденных ошибках.

### Загрузки

Моды скачиваются в фоне, до 3 одновременно, и их можно отменить. Установка идёт по одной.

### Конфликты

В карточке мода видно, кто побеждает в общих файлах. Кнопка «Сделать главным» переносит победу на этот мод.

### Вкладка NightCoop

Кооп-мод [NightCoop](https://nightcoop.net/download.html) ставится прямо из менеджера.

- Список сборок берётся из `https://nightcoop.net/releases.json`.
- Архив проверяется по SHA-256 из этого списка.
- Можно выбрать версию игры (2.5 или 2.31): от неё зависит, какая сборка RED4ext внутри архива.
- Есть кнопки «Обновить до последней» и «Установить конкретную сборку» (у всех в сессии должен быть один протокол).
- Есть список изменений последней версии.

### Вкладка Nexus

- **Вход.** Работает по личному API-ключу. Ключ хранится в зашифрованном виде (Windows DPAPI через Electron `safeStorage`).
- **Кнопка «Mod Manager Download»** на nexusmods.com открывает менеджер (ссылки `nxm://`). Мод сам скачивается и ставится. Работает и с бесплатным аккаунтом.
- **Установка по ссылке:** вставьте ссылку на мод и выберите файл. С Premium файл скачивается сразу, без сайта.
- **Проверка обновлений** установленных с Nexus модов идёт по цепочке `file_updates`.

#### Кнопка «Войти через Nexus» (SSO)

Nexus выдаёт SSO только зарегистрированным приложениям. После регистрации на Nexus пропишите
выданный идентификатор (slug) в `src/config.js` → `nexusAppSlug`. Кнопка «Войти через Nexus»
появится автоматически. Пока slug пустой, вход работает по API-ключу.

### Вкладка «Коллекции»

Коллекция передаётся кодом вида `MMC1-…`. В код попадают моды с Nexus и NightCoop. Моды, установленные
из своих файлов, передать нельзя: их неоткуда скачать. С Premium-аккаунтом друг ставит всё одной кнопкой.
С бесплатным аккаунтом менеджер по очереди открывает страницу каждого мода, и на каждой нужно нажать «Slow download».

## Как выпустить обновление

Обновления берутся из GitHub Releases репозитория `Lepotion/mmc-mod-manager` (`src/config.js` → `updateRepo`).

1. Поднимите версию в `package.json` (`"version"`), в `src/core/nexus.js` (`APP.version`) и в `src/renderer/index.html` (`v1.x`).
2. Соберите установщик: `npm run dist`.
3. Откройте https://github.com/Lepotion/mmc-mod-manager/releases/new.
4. **Tag:** `v<версия>`, например `v1.3.1` (Create new tag). **Title:** то же. В описании перечислите, что нового.
5. Перетащите в окно файл `dist/MMC-Mod-Manager-Setup-<версия>.exe` и нажмите **Publish release**.

При следующем запуске менеджер у всех покажет «Доступно обновление». Галочку «pre-release» не ставьте:
менеджер смотрит только на последний обычный релиз.

## Запуск

```bash
npm install
npm start
```

Сборка `.exe` (установщик и portable-версия появятся в `dist/`):

```bash
npm run dist
```

Тесты (второй тест скачивает настоящую сборку NightCoop, нужен интернет):

```bash
npm test
```

## Как это работает

Каждый мод хранится в `%APPDATA%\MMC Mod Manager\mods\<id>\files` уже в структуре папки игры.
При включении файлы копируются в игру, при выключении удаляются. Если мод заменяет файл, который
уже был в игре, оригинал переносится в `backups` и возвращается на место при выключении мода.
Если два мода меняют один и тот же файл, побеждает включённый последним.

## Структура

- `src/main.js`: окно Electron, IPC, обработка `nxm://`
- `src/config.js`: идентификатор приложения Nexus для SSO
- `src/core/manager.js`: установка, включение и выключение, бэкапы, профили
- `src/core/online.js`: скачивание с Nexus и nightcoop.net
- `src/core/nexus.js`: API Nexus Mods
- `src/core/download.js`: загрузчик с прогрессом и проверкой SHA-256
- `src/core/layout.js`: определение структуры мода
- `src/core/game.js`: поиск игры, проверка фреймворков
- `src/core/archive.js`: распаковка архивов
- `src/renderer/`: интерфейс (`i18n.js` содержит переводы RU/EN)
