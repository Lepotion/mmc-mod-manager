# Правила и лицензии: что нужно и зачем

Чеклист для MMC Mod Manager и будущего сайта MMC. Это не юридическая консультация: перед публичным
запуском сайта стоит показать его юристу.

Обозначения: ✅ сделано в приложении · 🟡 нужно сделать тебе · ⏳ сделать позже, при запуске сайта.

---

## 1. Nexus Mods

| Что | Зачем | Статус |
|---|---|---|
| Зарегистрировать приложение в Nexus | Правила API разрешают личный ключ только для тестов и личного пользования. Публичному приложению нужна регистрация, иначе Nexus может заблокировать приложение и ключи пользователей. | 🟡 письмо ниже |
| После регистрации вписать slug в `src/config.js` → `nexusAppSlug` | Тогда в менеджере появится «Войти через Nexus» (SSO), и ключ будет выдаваться именно этому приложению. | 🟡 после ответа Nexus |
| Ключ пользователя используется только по его действию | Правило Nexus: ключ нельзя использовать, если действие начал не пользователь. Автопроверка обновлений теперь выключена по умолчанию и включается отдельным переключателем с объяснением. | ✅ 1.7.0 |
| Честные заголовки `Application-Name` / `Application-Version` | Требование Nexus: одно и то же имя во всех версиях и без подделки чужого приложения. | ✅ `src/core/nexus.js` |
| Без массового копирования данных Nexus | Правило Nexus запрещает выгружать данные и выкладывать их на своём сервисе. Каталог загружается, только когда его открывают, а в кодах коллекций лежат только номера модов. | ✅ |
| Не хранить ключи Nexus на своём сервере | Прямо запрещено правилами Nexus. | ✅ ключ лежит только на компьютере пользователя, зашифрован через DPAPI |
| Без Premium скачивание только через кнопку на сайте | API не выдаёт бесплатному аккаунту ссылку без клика на сайте. Автоклики не делаем: это обход ограничений, за который банят. | ✅ |
| Не использовать логотип Nexus | Правила не разрешают его явно. Название «Nexus Mods» упоминается только текстом. | ✅ |
| Пометка «не связано с Nexus Mods» | Чтобы никто не думал, что это официальное приложение Nexus. | ✅ вкладка Nexus, «О программе» |

### Письмо в Nexus (support@nexusmods.com)

> **Subject:** API application registration — MMC Mod Manager (Cyberpunk 2077)
>
> Hello! I'd like to register a public application that uses the Nexus Mods API.
>
> - **Name:** MMC Mod Manager
> - **Game:** Cyberpunk 2077
> - **What it does:** a free, non-commercial Windows mod manager. It installs, enables and disables mods,
>   handles FOMOD installers, requirements, collections shared as short codes (mod/file IDs only, no
>   rehosting) and update checks.
> - **API usage:** v1 (`users/validate`, `mods/{id}`, `mods/{id}/files`, `download_link` with nxm key/expires
>   for free users), v2 GraphQL for browsing the catalog on demand. All requests are started by the user,
>   with honest `Application-Name` / `Application-Version` headers. Keys are stored only on the user's PC,
>   encrypted with Windows DPAPI, and never sent to any other server.
> - **Downloads:** free users press "Slow download" on the website (nxm:// handler); Premium users download
>   in the app.
> - **Testing build:** https://github.com/Lepotion/mmc-mod-manager/releases/latest
> - **Source code (GPL-3.0):** https://github.com/Lepotion/mmc-mod-manager
> - **Logo:** attached (512×512, works on a dark background).
>
> I'd like to use SSO once the application is approved. Thank you!

Приложи: установщик (или ссылку на релиз), `build/icon.png`. Если решишь открыть исходный код,
дай ссылку на репозиторий: Nexus пишет, что это ускоряет регистрацию.

| Компонент | Лицензия | Что требуется | Статус |
|---|---|---|---|
| Electron / Chromium | MIT / BSD и другие | Приложить тексты лицензий | ✅ `LICENSE.electron.txt`, `LICENSES.chromium.html` (electron-builder) |
| 7-Zip (7za.exe через 7zip-bin) | GNU LGPL + BSD 3-clause | Приложить лицензию и указать, где взять исходники (7-zip.org) | ✅ `build/THIRD_PARTY_NOTICES.txt` |
| UnRAR (через node-unrar-js) | Лицензия UnRAR | Приложить лицензию; нельзя использовать код для создания RAR-архиватора (мы только распаковываем) | ✅ |
| fast-xml-parser, strnum | MIT | Приложить лицензию | ✅ |
| Наш код | GNU GPL v3 (как у Vortex) | Текст лицензии в `LICENSE`, ссылка на исходники в «О программе» | ✅ github.com/Lepotion/mmc-mod-manager |

Файл со списком собирает `scripts/notices.js` при каждом `npm run dist`. В приложении он открывается
через «Настройки → О программе → Лицензии». Если добавишь новую библиотеку, допиши её в список в этом скрипте.

MMC Clips и MMC Shots (FFmpeg под GPL, сервисы загрузки) разбираются в их собственных `docs/COMPLIANCE.md`.

## 7. Открытые вопросы

1. **Кто «оператор»: физлицо или самозанятый?** Политике конфиденциальности нужен конкретный человек или
   организация и контакт. «MongaManiaCorporation» — это просто название, а не юрлицо.
2. ~~Открывать ли исходный код?~~ Решено: код открыт под GPL v3, как у Vortex. Копии тоже обязаны
   оставаться открытыми.
3. **Подпись кода.** Без сертификата Windows SmartScreen и антивирусы предупреждают пользователей.
   Это не нарушение, но подпись сильно повышает доверие.
